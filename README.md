# Student Performance Prediction based on Particle Swarm Optimization (S3PSO)

# Project Overview
This M.Tech project predicts student performance (Pass/Fail) using Particle Swarm Optimization (PSO).  
The model optimizes subject-wise weights to improve prediction accuracy and provides an interactive dashboard for analysis.

# Objectives
- Predict student Pass/Fail status based on subject marks
- Optimize weights using S3PSO (Swarm-based optimization)
- Visualize performance metrics using an interactive Dash dashboard
- Analyze absence days and extracurricular activities impact

# Methodology
1. Load student dataset (Excel file)
2. Preprocess subject marks and attributes
3. Apply S3PSO to optimize subject weights
4. Predict Pass/Fail outcomes
5. Evaluate using Precision, Recall, F1-score, Accuracy
6. Display results in Dash dashboard with graphs and tables

# Features
- Subject-wise performance visualization
- Absence days analysis
- Extracurricular activity distribution
- PSO-based prediction analytics
- Interactive student dashboard

# Technologies Used
- Python
- Pandas, NumPy
- Particle Swarm Optimization (PSO)
- Scikit-learn
- Plotly & Dash (for dashboard)
